# Estacion-Climatica
Se requiere procesar N pares de temperaturas (máxima, mínima) y los nombres de los días en una estación climática. El objetivo es identificar días con temperaturas máximas entre 15 y 20 grados, días con mínimas por debajo de 0 grados, calcular las medias de temperaturas máximas y mínimas, y mostrar un listado completo de temperaturas por día.
